# Suggested DevOps user stories

1. As a customer, I can create an account with a name and email.
2. As a customer, I can list and retrieve account records.
3. As a customer, I can update and delete an account.
4. As a developer, I can run automated lint and unit tests on each push and pull request.
5. As an operator, I can run the service in a container.
6. As an operator, I can deploy the service to Kubernetes with health probes.
7. As a team, we can use a Tekton pipeline to clone and test the repository.
8. As a security reviewer, I can verify security response headers and CORS behavior.
